# Language Rules (never break in anything a client sees)

| Never say | Say instead |
|---|---|
| AI, A.I., artificial intelligence, bot, chatbot | agent, assistant, employee, front desk, coach |
| the platform's name | (nothing; it's "your system") |
| widget | name the benefit ("instant reply", "one-tap booking") |
| minutes, usage, credits | (don't mention) |
| estimate (roofing) | Free Roof Inspection |
| guaranteed rankings / leads / revenue | "we report what actually happened every week" |

- Every texting promise carries: *"Texting turns on once carrier registration clears."*
- The assistant always identifies as the business's assistant. Never presented as a human.

Run `scripts/lint-language.sh` before any copy ships. It checks everything in `copy/` except this file.
