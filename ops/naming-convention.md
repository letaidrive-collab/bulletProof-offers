# Naming Convention (holds at 1,000 sub-accounts)

- Sub-account: `{BusinessName} — {Town}` (one per location)
- Workflows: `FD-` Front Door · `DESK-` Front Desk · `REV-` Revive & Review · `ADS-` Fill the Bucket, then two-digit number + short name (`FD-01 New Lead`)
- SMS templates: `{prefix}-SMS-{nn}`
- Tags: lowercase-hyphen: `lead-web`, `lead-ads`, `job-complete`, `consent-sms`, `no-consent`, `offer-1` … `offer-4`
- Pipelines: `Leads`, `Reactivation`
- Snapshot versions: `bp-offers-v{major}.{minor}` + changelog line in this repo
